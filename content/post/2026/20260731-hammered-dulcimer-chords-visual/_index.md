I have been learning a bit more about music theory and chords, so I made myself a page which lists major/minor chords that can be found on a given hammered dulcimer. An interesting feature of the instrument is that some notes are located in multiple locations - meaning chords can be played in multiple ways. I still need to learn music theory a bit better and better understand technical terms and all the different modes.

The tool also annotates if it is a well-known shape, plays a MIDI preview of the chord, and highlights strikes on the note diagram I previously made.
