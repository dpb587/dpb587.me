          %}\n\n1\\. When the filament track switch is installed on the X2D printer,
          how many AMS units can be connected at most?\n\nA: The number of AMS units
          the printer can connect to is **independent of whether the filament track
          switch is installed**, so the X2D supports up to 4 AMS 2 Pro and 8 AMS HT
          units simultaneously—12 units with 24 slots in total—linked via the 4-in-1
          PTFE adapter.\n\n2\\. Can the 4-in-1 PTFE adapter be used when only two
          AMS units are connected?\n\nA: Using the 4-in-1 PTFE adapter with just two
          AMS units is **strongly discouraged**; the extra resistance during loading
          and unloading can compromise print reliability.\n\n3\\. Can the filament
          track switch be connected to an external spool?\n\nA: No. When using an
          external spool, it will permanently occupy one extruder channel, making
          the filament track switch unable to dynamically map filament from the AMS
          to the two extruders. Therefore, if you need to print with an external spool,
          you need to remove the filament track switch.\n\n4\\. Are there filament
          restrictions when printing with the filament track switch?\n\nA: Certain
          filaments—such as PLA-CF, PLA Glow, and PLA Silk—are more sensitive to feed
          resistance and may fail to load or unload. Avoid using these filaments through
          the switch. If problems occur and printing must continue, try:\n\n- Manually
          moving the problematic filament to another AMS slot;\n- Using the officially
          recommended PTFE tube length;\n- Arranging the AMS units as advised in the
          official guidelines.\n\nIf issues persist, disable the filament track switch
          for the current print job.\n\n5\\. What should I do if the filament track
          switch is clogged?\n\nA: If the filament track switch is clogged, please
          refer to [filament track switch disassembly and troubleshooting guide](https://wiki.bambulab.com/en/general/troubleshooting/filament-track-switch)
          to clear the clog.\n\n6\\. What should I do if the filament gets stuck at
          the filament track switch outlet?\n\nA: If the filament gets stuck at the
          filament track switch outlet, you can try the following solutions:\n\n-
          Reconnect the PTFE tube between the filament track switch and the filament
          buffer.\n- Install the pneumatic connector locking tab on the filament track
          switch outlet.\n- Replace the PTFE tube between the filament track switch
          and the filament buffer.\n\n7\\. Can the printer perform calibration when
